## 学习建议

### 课程要求

- 课程内容：面向对象编程（OOP）+ EasyX图形库
- 大作业：使用EasyX实现一个可运行的小游戏

### 注意事项

- 往届大作业多以录制视频提交，部分教学班安排当堂展示。
- 往届同学通常在课程结束后离校。想在完成大作业后提前离校，可以向授课教师申请。
- 有同学反映大二学年专业课与代码实践关联度较低，建议珍惜小学期C++ 课程的编程机会。
- 授课教师范晓雅有概率讲着讲着出现问题时会询问同学"我应该没错吧，是哪里出错的"，属于比较"接地气"的教学风格。
