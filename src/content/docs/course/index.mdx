除公共基础与通识课程外，专业课程按照开课单位分类。

课程按开课单位分类，不等同于按校区分类。同名课程在不同校区、学院、教学班或学年的安排可能不同，请确认文章中的适用范围；“公共基础与通识课程”也不表示其考核经验适用于全校所有教学班。

本章集中收录选课、考试、体育、课程资料、各开课单位的课程经验及毕业相关内容。校园网络、证明证件、报修与资助奖励等见[校园服务](/services/)。
